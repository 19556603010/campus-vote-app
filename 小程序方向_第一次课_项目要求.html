《项目实训（一）》小程序方向 — 第一次课

AI 编程 · 微信小程序 · 云开发

⚠️ 重要说明
1. 本次课程为全新方向（微信小程序），与之前纯前端项目独立，所有同学从零开始。
2. 第一次课核心任务：环境搭建 + 项目初始化 + 确定方向，不要求完成完整功能。
3. 每人独立完成一个微信小程序，通过体验版提交验收。
4. 开发工具统一使用 Trae IDE 进行 AI 辅助编程，微信开发者工具仅用于预览和上传。

📋 课前准备（务必在课前完成）

一、安装必备软件

  • Trae IDE：https://www.trae.com.cn/（国内版）
  • 微信开发者工具：官方下载页面（选 Stable 稳定版）
  • Node.js LTS：https://nodejs.org/zh-cn/download（选 18.x 或 20.x）
  • Git for Windows：https://git-scm.com/download/win

二、注册微信小程序账号

  • 访问 https://mp.weixin.qq.com
  • 选择「小程序」→ 主体类型选「个人」
  • 完成实名认证（需身份证 + 手机号 + 微信扫码）
  • 小程序类目选「其他」，注册国家/地区选「中国大陆」
  • 记录 AppID（wx 开头的一串字符），创建项目时必须用到

🛠️ 课堂任务（第一次课完成目标）

任务一：创建微信小程序项目

  • 打开微信开发者工具 → 新建项目 → 填写 AppID
  • 后端服务选择「微信云开发」
  • 模板选择「云开发基础模板（官方）」
  • 项目目录建议放在 E:\code\miniapp-xxx 等无中文无空格的路径
  • 创建成功后，左上角点击「云开发」按钮，开通免费云开发环境

任务二：Trae 与微信开发者工具联动

  • 在 Trae 中打开刚才创建的项目目录（同一个文件夹）
  • 在 Trae 中修改 miniprogram/pages/index/index.wxml 中的文字
  • 按 Ctrl+S 保存
  • 切换回微信开发者工具，确认模拟器自动刷新并显示改动
  • 联动成功标志：Trae 改代码 → 微信工具自动编译预览

任务三：确定项目方向（个人自选）

以下三个方向任选其一。每个方向只规定核心机制，具体玩法、主题、视觉风格由你自行发挥创意。

🎮 方向一：轻量小游戏

🎮 方向一：轻量小游戏

利用微信小程序的触摸交互和本地存储能力，做一款即开即玩的轻量游戏。适合喜欢游戏、对交互逻辑感兴趣的同学。

核心机制（必须实现）
  • 有明确的游戏目标（如得分、通关、存活时间）
  • 有用户输入响应（点击、滑动、长按等）
  • 有胜负或结束判定（游戏何时结束、如何算赢/输）
  • 有分数或进度记录，使用云数据库存储
创意参考（不限于此）：跳跃闯关、记忆翻牌、节奏点击、物理弹射、迷宫探索、合成消除、答题闯关

🧰 方向二：实用工具

🧰 方向二：实用工具

解决校园生活中的实际问题，利用云开发实现数据持久化。适合喜欢"做有用东西"、注重实用性的同学。

核心机制（必须实现）
  • 有明确的输入 → 处理 → 输出流程
  • 数据使用云数据库存储，换设备登录数据不丢失
  • 至少包含2个相关功能页面（如列表页 + 详情页）
  • 有基本的数据增删改查操作
创意参考（不限于此）：班级值日排班、课程表管理、寝室水电费分摊、图书馆占座提醒、社团活动报名、二手物品交换、学习打卡记录

💬 方向三：社交互动

💬 方向三：社交互动

利用微信小程序的分享能力和云数据库，做一款能让同学之间产生互动的小程序。适合喜欢社交产品、想尝试多人协作场景的同学。

核心机制（必须实现）
  • 有多人共享的数据（不是只存在自己手机里的本地数据）
  • 有用户身份区分（如发起者 vs 参与者）
  • 有互动动作（投票、报名、留言、组队等）
  • 有结果展示（排行榜、统计、名单等）
创意参考（不限于此）：班级匿名投票、活动报名组队、真心话大冒险、校园树洞留言、拼单凑人、失物招领、课堂随机点名

✅ 第一次课验收标准（下课前完成）

环境搭建（必须全部完成）

  • 微信小程序账号注册成功，拿到 AppID
  • 微信开发者工具能正常创建项目并运行
  • 云开发环境开通成功（显示"免费开发环境"）
  • Trae 能打开项目目录，修改代码后微信工具自动刷新
  • GitHub 仓库已创建，项目代码已 push

项目初始化（至少完成）

  • 已确定个人项目方向（游戏 / 工具 / 社交互动）
  • 已在 Trae 中向 AI 描述项目需求，生成初步页面结构
  • 至少完成 1 个可运行的页面（有基本界面，能显示内容）
  • GitHub README 已更新，写明项目名称、方向、个人姓名

📤 提交要求

下课前提交以下内容

  • GitHub 仓库链接（代码已 push）
  • 项目方向确认（一句话说明做什么）
  • 体验版二维码截图（证明已上传体验版，可选）

📊 评分标准（第一次课占比 20%）

  • 环境搭建完成度（40%）：账号、工具、云开发、Trae 联动是否全部就绪
  • 项目初始化质量（30%）：方向是否明确、页面是否有基本雏形
  • 代码规范（20%）：GitHub 提交记录是否清晰、README 是否完整
  • AI 工具使用（10%）：是否有效利用 Trae AI 辅助编程
